# A road-kill hotspot map

Turns scattered reports of animals hit by vehicles into evidence a city can act on.

## The problem
Huge numbers of street dogs, cattle and wild animals are hit by vehicles on Indian roads, and most of these deaths happen again and again at the same dangerous stretches: a bend near a market, a highway that cuts through a forest. Authorities can install speed breakers, warning signs, lights or animal underpasses, but only where someone shows them evidence. Single reports disappear into chat groups, and nobody sees the pattern.

## How it works
Every computer does four jobs: input, processing, storage and output. Design the solution as those four jobs and it almost writes itself: reports come in, get grouped by place, are kept as growing evidence, and come out as a ranked list an official can act on.

## Run it
```
python hotspots.py
python test_hotspots.py
```
